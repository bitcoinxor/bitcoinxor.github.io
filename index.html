Tools for the day the hash changes.

Independent, open-source tooling for the BIP-110 proof-of-work-change hard fork of Bitcoin — a miner, a non-custodial pool, and an explorer. Built by an enthusiast, in the open, before launch day.

the tools

⊕ xorminer

released · experimental

A getblocktemplate miner with pluggable hash kernels — CPU reference included, GPU kernels drop in behind a documented protocol. Builds templates from your own node.
xorminer.com · source

⊕ xorpool

built · not yet operating

A TIDES-style pool coordinator that never holds funds — every block pays its miners directly in the coinbase, split over a published share window. Python reference and production Java implementation, wire-compatible.
xorpool.com · source

A block explorer that follows the fork chain as first-class — live at this domain when the network is.
